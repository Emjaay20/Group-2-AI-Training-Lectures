# Lab ideas file (conceptual only)

File: `LabIdeas.txt` in the class repo.

The written idea: law-enforcement OSINT that uses NLP the way Lab 1 / sentiment labs use it — take messy open text and extract structured fields (actors, places, times).

## How the tutor should teach this
- Emphasise the **pattern already practised**: scrape or ingest text → clean → model → JSON the human can check.
- Public news, official statements, and classroom sample files are the right examples.
- Do **not** provide methods for reaching dark web markets, breaking encryption, writing malware, building weapons, or targeting people.
- If asked to go there, refuse the methods and return to: “In this course we structured public headlines and labels. That is the transferable skill.”
